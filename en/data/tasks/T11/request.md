# T11 · Delayed-order notice

When an order is delayed, the customer has to get an email. Add to notices.py a function
`delay_notice(number, order, customer)` with the same greeting and the same signature as
the other notices and a body like this one: "Your order NC-11302 has been delayed (size L
out of stock). The new expected delivery date is 10/15/2026. We apologize for the
inconvenience."

— Bea (customer service)
