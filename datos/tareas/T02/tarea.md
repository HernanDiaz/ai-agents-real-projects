# T02 · Códigos postales sin el cero inicial

A Marina Bauzá (pedido CN-11455, de Palma) le cobramos 4,95 € de envío, la tarifa de la
península, en vez de 9,95 €. En la base de datos su código postal aparece como 7002: al
importar los pedidos antiguos se perdió el cero inicial. Que el programa calcule bien la
zona aunque el código postal venga así.

— Bea (atención al cliente)
