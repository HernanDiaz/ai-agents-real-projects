# T11 · Aviso de pedido retrasado

Cuando un pedido se retrasa, el cliente tiene que recibir un correo. Añadid a avisos.py
una función `aviso_retraso(numero, pedido, cliente)` con el mismo saludo y la misma firma
que los demás avisos y un cuerpo como este: «Tu pedido CN-11302 se ha retrasado por falta
de existencias en la talla L. La nueva fecha prevista de entrega es el 15/10/2026.
Sentimos las molestias.»

— Bea (atención al cliente)
